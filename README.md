# FocusDrive-AI
FocusDrive AI uses a car camera to detect phone use while driving and sends audio alerts to refocus drivers, helping prevent distracted driving and save lives. 

To run this program: 
Download both the main py file and audio mp3 file. 
Make sure to also install these on command prompt: 
pip install ultralytics opencv-python pygame
pip install mediapipe
in order for the YOLO AI and OpenCV to be launched. 

Import the files onto Visual Studio Code and run program. 


We all know that teenagers, especially Gen Z, use their phones anywhere and everywhere. Teen drivers use phones to text or even scroll while driving and in traffic, statistics from Children's Hospital of Philadelphia show that “In 2019, 39% of high school students reported texting or emailing while driving during the past month.” Even though, Iphone added a feature that questions if you are driving while your phone is in motion, teenagers tend to lie towards it and say no. Teenagers need a real safety feature that detects a phone in their hand through their car camera. Therefore, FocusDrive AI scans your face, detects if you are distracted by your phone in your hand while driving to send you audio alerts to help you focus. Moreover, this feature will certainly help reduce the number of distracted teenage drivers, keeping them away from their phones while driving, helping them save their lives and others caught in danger.
